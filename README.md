# YEET A GOOBER! [MUTATIONS] — Roblox Luau MVP

Полный рабочий MVP-проект игры **«YEET A GOOBER! [MUTATIONS]»** на **Luau**, полностью совместимый с **Rojo 7+** (`default.project.json`).
Весь пользовательский интерфейс (`ScreenGui`) и тестовая 3D-карта создаются **100% программно** при запуске — ручная сборка объектов в Roblox Studio не требуется.

---

## Структура проекта

```text
├── default.project.json                  # Конфигурация синхронизации Rojo
├── ReplicatedStorage/
│   └── Modules/
│       ├── GooberConfig.lua              # 6 базовых видов + 2 редких гостя, вес 0.5–1000 кг, физика мутаций
│       └── RemoteNames.lua               # Единый реестр RemoteEvent'ов
├── ServerScriptService/
│   ├── ServerInit.server.lua             # Серверная точка входа (создание Remotes, карты и запуск сервисов)
│   ├── MapGenerator.lua                  # Авто-генератор 3D-горы, обрыва, инкубатора, баз, батутов и колец
│   ├── DataManager.lua                   # Сохранение монет, уровня Ботинка, инвентаря и базы (DataStore + pcall)
│   ├── IncubatorService.lua              # Выращивание Губера за 5 сек и взятие модели в руки
│   ├── LaunchService.lua                 # Физический пинок (ApplyImpulse), PERFECT YEET (x3), комбо x1.5, награды
│   ├── BaseService.lua                   # База игрока на 4 пьедестала и пассивный доход монет в секунду
│   └── ShopAndMonetization.lua           # Прокачка Ботинка за монеты + Game Pass'ы через MarketplaceService
└── StarterPlayerScripts/
    ├── ClientInit.client.lua             # Клиентская точка входа
    ├── UIController.lua                  # Программный адаптивный UI (смартфоны / планшеты / ПК)
    └── KickController.lua                # Шкала заряда 0–100% (зелёная зона 85–95%), плавная камера и подруливание
```

## Реализованные механики

1. **Виды Губеров (`GooberConfig.lua`)**:
   - **6 базовых видов**: *Слаймик, Черничка, Солнышко, Жвачка, Лавовик, Космо-Пупс* (сферы разного цвета/материала с лицом-декалью).
   - **2 редких гостя**: *Жирный Арбуз* и *Проклятый Носок* с уникальным декором и повышенной ценностью.
   - **Генератор веса (0.5 – 1000 кг)**: чем тяжелее Губер, тем физически больше диаметр его сферы и выше множитель награды и пассивного дохода.
2. **Мутации полёта**:
   - **Обычная** — сбалансированная баллистика.
   - **Пружинная** — максимальная упругость отскока (`Elasticity = 1.0`, `ElasticityWeight = 100`).
   - **Тяжёлая** — высокая плотность (`Density = 6.0`), сносит деревянные преграды на склоне и даёт бонус к комбо.
   - **Воздушная** — пониженная гравитация через `VectorForce` в мировых осях (`RelativeTo = World`).
3. **Пинок, комбо и камера**:
   - У жёлтой линии обрыва зажмите ЛКМ / экран (или мобильную кнопку **«🦵 ЗАЖМИ ПИНОК!»**).
   - Попадание в зелёную зону **85–95%** активирует **«PERFECT YEET! (x3)»**.
   - Касание батутов и пролёт сквозь кольца увеличивает комбо-множитель (**x1.5**) и спавнит всплывающую 3D-цифру награды прямо над Губером.
   - Камера плавно следует за Губером до полной остановки в зоне приземления.
4. **База и пассивный доход (`BaseService.lua`)**:
   - После приземления игрок выбирает: **забрать монеты сразу** ИЛИ **поставить Губера на один из 4 пьедесталов своей базы** для ежесекундного дохода.
5. **Магазин и монетизация (`ShopAndMonetization.lua`)**:
   - Прокачка уровня **Ботинка** за монеты (увеличивает импульс броска).
   - Поддержка Game Pass **Meme Sound Pack** и **Jetpack Steering** через `MarketplaceService` (для релиза укажите свои `PassId` в `ReplicatedStorage/Modules/GooberConfig.lua`; при `PassId = 0` в Roblox Studio включён тестовый режим разблокировки).

## Инструкция по запуску и синхронизации через Rojo

### Шаг 1. Установка Rojo
1. Установите **Rojo CLI** (рекомендуется версия `7.4+`) через [Rokit](https://github.com/rojo-rbx/rokit), [Aftman](https://github.com/LPGhatguy/aftman) или релизы GitHub:
   ```bash
   rojo --version
   ```
2. Установите плагин **Rojo** в **Roblox Studio** (через вкладку *Plugins* или `rojo plugin install`).

### Шаг 2. Запуск сервера синхронизации
Откройте терминал в корне репозитория (рядом с `default.project.json`) и выполните:
```bash
rojo serve
```
По умолчанию сервер запустится на `localhost:34872`.

*(Альтернатива — сборка готового файла плейса одной командой)*:
```bash
rojo build default.project.json -o YeetAGoober.rbxlx
```

### Шаг 3. Подключение в Roblox Studio
1. Откройте **Roblox Studio** и создайте пустой плейс (**Baseplate** или **Empty**).
2. Перейдите во вкладку **Plugins -> Rojo** и нажмите **Connect** (`localhost:34872`).
3. Убедитесь, что скрипты появились в `ReplicatedStorage/Modules`, `ServerScriptService` и `StarterPlayer/StarterPlayerScripts`.
4. *(Опционально для сохранения данных между сессиями)*: чтобы `DataStoreService` сохранял прогресс в облако Roblox, опубликуйте плейс и включите **File -> Game Settings -> Security -> Enable Studio Access to API Services**. Без этой настройки игра также полностью работает в рамках текущей сессии благодаря защите `pcall`.
5. Нажмите **Play (F5)** — 3D-гора, инкубатор, базы и весь интерфейс создадутся автоматически!
