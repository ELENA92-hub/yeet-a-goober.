# YEET A GOOBER! [MUTATIONS] — Roblox Luau (Rojo `src/`)

Драйвовый, смешной и глубокий редизайн игры **«YEET A GOOBER! [MUTATIONS]»** на **Luau** с поддержкой **Rojo 7+** (`default.project.json` + папка `src/`). Весь интерфейс (`ScreenGui`) и 3D-карта создаются **100% программно** при запуске — ручная сборка в Studio не нужна.

---

## Структура проекта (Rojo `src/`)

```text
├── default.project.json                  # Rojo 7: name = "YEET_A_GOOBER_MUTATIONS"
│                                         # ReplicatedStorage.Modules -> src/shared
│                                         # ServerScriptService       -> src/server
│                                         # StarterPlayerScripts      -> src/client
├── src/shared/
│   ├── GooberConfig.lua                  # Виды, Конструктор, мутации, физика, 3D-сборка
│   └── RemoteNames.lua                   # Единый реестр RemoteEvent'ов
├── src/server/
│   ├── ServerInit.server.lua             # Точка входа: создаёт Remotes + карту + сервисы
│   ├── MapGenerator.lua                  # Гора, обрыв, инкубатор, 6 баз, склон, трасса трюков
│   ├── DataManager.lua                   # DataStore (pcall): монеты, Ботинок, рюкзак, пьедесталы, пресеты Мастерской
│   ├── IncubatorService.lua              # Мастерская Губера: сборка, выращивание 3D-модели, выдача в руки
│   ├── BaseService.lua                   # 4 пьедестала на базу + пассивный доход (MaxDistance = 45)
│   ├── LaunchService.lua                 # Физика полёта, руление, Рывок, комбо, бонусы и препятствия
│   └── ShopAndMonetization.lua           # Прокачка Ботинка + Game Pass'ы (MarketplaceService)
└── src/client/
    ├── ClientInit.client.lua             # Точка входа: UI + камера + клиентская анимация
    ├── UIController.lua                  # Программный русский UI: Мастерская, Магазин, База, Рюкзак, Landing
    └── KickController.lua                # Шкала заряда 0–100% (85–95% = PERFECT x3), FOV, тряска, управление
```

## Что нового в редизайне

### 1. Конструктор Губера («Мастерская Губера» / стикеры)
- Окно **«🎨 Мастерская Губера»** открывается кнопкой в верхней панели или при нажатии «Вырастить».
- Игрок собирает уникального чудика из частей:
  - **Форма тела:** Желе (`Jelly`), Кубик (`Cube`), Капля (`Drop`), Пончик (`Donut`).
  - **Глаза:** Выпученные (`Bulging`), Злые (`Angry`), Аниме (`Anime`), Циклоп (`Cyclops`).
  - **Рот:** Кричащий (`Screaming`), с языком (`Tongue`), усы (`Mustache`).
  - **Аксессуары:** Пропеллер (`Propeller`), Корона (`Crown`), Очки (`Sunglasses`), Реактивный ранец (`Jetpack`).
- Каждая деталь **визуально отображается** на 3D-модели (сварные `Part`/`WeldConstraint` + частицы) **и даёт реальный бонус**: планирование, таран стен, щит, рывок, магнит монет, комбо.

### 2. Драйвовый полёт, управление и адреналин
- Плавная **камера преследования** с **динамическим FOV (70 → 98)** по ощущению скорости, **трейлом** и **линиями ветра** по краям экрана.
- **Управление в воздухе:** `A/D` или `←/→` (мобильные кнопки `◀ / ▶`) + **«⚡ РЫВОК [SPACE]»** с серверным откатом (бонусы от Ранца и VIP-пасса).
- **Тряска камеры**, смешные звуки (`GooberConfig.Sounds`), физический **отскок/рагдолл** и система **Комбо-множителя** за серию трюков без касания земли.

### 3. Препятствия и поощрения на трассе (разная высота и дистанция)
- **Поощрения:** золотые кольца ускорения, батуты-облака, воздушные потоки, парящие монеты (магнит от Пончика/глаз), редкие кристаллы мутаций (дают Щит).
- **Препятствия:** крутящиеся лопасти вентиляторов, грозовые тучи (удар током — или **СУПЕР-МУТАЦИЯ**, если влететь со Щитом!), летающие преграды, пробиваемые стены (на скорости или Рывком).

### 4. Исправление визуала баз
- Для всех `BillboardGui` над базами и слотами пьедесталов задан **маленький шрифт** (`MaxTextSize 13/11/10`) и **`MaxDistance = 45`**, чтобы подписи не накладывались и не засоряли экран.

## Базовые сохранённые механики
- **6 базовых видов + 2 редких гостя** (Слаймик, Черничка, Солнышко, Жвачка, Лавовик, Космо-Пупс + Жирный Арбуз, Проклятый Носок) с весом **0.5–1000 кг** (чем тяжелее — тем больше диаметр и выше множитель ценности).
- **Мутации:** Обычная, Пружинная, Тяжёлая, Воздушная + **Супер-мутация «Грозовой Бог»** (выдаётся в полёте при пробитии тучи под Щитом).
- **DataStore `pcall`-сохранение**: монеты, уровень Ботинка, лучший результат, рюкзак, пьедесталы, пресеты Мастерской и Game Pass'ы.
- **Инкубация 3.5 сек** и **пинок 0–100%** (зелёная зона **85–95% = PERFECT YEET x3**).
- **База на 4 пьедестала** с пассивным доходом монет в секунду.
- **Прокачка Ботинка** за монеты и **Game Pass'ы** (`MemeSoundPack`, `Turbo Jetpack VIP`) через `MarketplaceService`.
- **100% программный UI** и **авто-генерация 3D-карты** на старте сервера; оптимизировано для мобилок.

## Запуск через Rojo

### Шаг 1. Установка Rojo
```bash
rojo --version   # рекомендуется 7.4+
```
Установите плагин **Rojo** в **Roblox Studio** и сервис синхронизации (`rojo serve` на `localhost:34872`).

### Шаг 2. Синхронизация
```bash
rojo serve
# или сборка плейса:
rojo build default.project.json -o YeetAGoober.rbxlx
```

### Шаг 3. Подключение в Studio
1. Создайте пустой плейс (Baseplate).
2. `Plugins → Rojo → Connect` (`localhost:34872`).
3. Убедитесь, что `ReplicatedStorage/Modules`, `ServerScriptService` и `StarterPlayerScripts` заполнились из `src/`.
4. Для сохранения прогресса: опубликуйте плейс и включите `Game Settings → Security → Enable Studio Access to API Services` (без этого игра работает в рамках сессии благодаря `pcall`).
5. Нажмите **Play (F5)** — гора, инкубатор, базы, трасса и весь UI создадутся автоматически!

## Управление
- **Сборка чудика:** `🎨 Мастерская` → выбери форму/глаза/рот/аксессуар → `🧬 Вырастить чудика!` → `🤲 Взять в руки`.
- **Пинок:** у жёлтой линии обрыва **зажми ЛКМ / тап** (или кнопку `🦵 ЗАЖМИ ПИНОК!`) и отпусти в зелёной зоне **85–95%**.
- **Полёт:** `A/D` или `←/→` (мобильные `◀ / ▶`) — руление; `Space` / клик / `⚡ РЫВОК` — рывок; `⏭ Пропустить камеру` — вернуть камеру к персонажу.
- **После приземления:** `💰 Продать` или `🏠 На пьедестал` (доход каждую секунду).
